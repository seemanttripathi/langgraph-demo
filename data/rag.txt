Retrieval-Augmented Generation (RAG)

RAG is a technique that combines information retrieval with
large language model generation.

A typical RAG pipeline contains document ingestion, document
chunking, embedding generation, vector storage, retrieval,
and generation.

During ingestion, documents are loaded and divided into smaller
chunks. Each chunk is converted into a numerical vector using
an embedding model. These vectors are stored in a vector
database.

When a user asks a question, the question is converted into
an embedding. The vector database performs similarity search
to retrieve the most relevant document chunks.

The retrieved chunks are then provided to a large language
model as context. The model uses this context to generate
an answer.

Common similarity measures include cosine similarity,
dot product, and Euclidean distance.

RAG can help an application answer questions using information
that was not present in the model's original training data.
It can also make information easier to update because the
knowledge base can be updated without retraining the LLM.

A production RAG system commonly separates ingestion from
query processing. Ingestion is responsible for loading,
chunking, embedding, and indexing documents. The query path
is responsible for retrieving relevant chunks and generating
an answer.
